# Módulo 57 — Projeto Final: Loja Virtual

## Objetivo

Consolidar o aprendizado por meio da construção de consultas, indicadores e relatórios gerenciais para o banco Loja Virtual.

## Cenário

A diretoria deseja acompanhar vendas, clientes, produtos, estoque, pagamentos, transportadoras e desempenho da equipe comercial.

## Entregáveis

- Dashboard executivo de vendas.
- Ranking de clientes.
- Curva de produtos por faturamento.
- Ticket médio mensal.
- Taxa de cancelamento.
- Conversão de pedidos pagos.
- Margem estimada por produto e categoria.
- Estoque crítico e cobertura.
- Desempenho por vendedor.
- Prazo e participação por transportadora.
- Relatório de inadimplência e pagamentos pendentes.

## Requisitos técnicos

O aluno deverá utilizar, conforme aplicável:

- Joins.
- Agrupamentos.
- Subqueries.
- CTEs.
- Window functions.
- CASE.
- Views.
- Índices e Explain Plan.
- Procedures ou packages para rotinas consolidadas.

## Etapas

1. Validar os dados do banco.
2. Criar consultas analíticas.
3. Criar views para relatórios.
4. Avaliar planos de execução.
5. Documentar conclusões de negócio.

Consulte `desafios.md` para o escopo completo e `solucoes.sql` somente após finalizar sua tentativa.
