# Erros comuns — DISTINCT

- Achar que altera os dados da tabela.
- Pensar que só a primeira coluna será distinta.
- Esperar ordenação automática.
- Confundir propósito com `GROUP BY`.
- Usar para esconder duplicidade de join.
- `ORA-01791`: ordenar por expressão incompatível com a lista de um `SELECT DISTINCT`.
