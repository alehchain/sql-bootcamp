# Banco Loja Virtual

Execute os arquivos na ordem numérica.

| Ordem | Arquivo | Finalidade |
|---|---|---|
| 0 | `00-drop-objects.sql` | Limpa objetos existentes |
| 1 | `01-schema.sql` | Cria tabelas e constraints |
| 2 | `02-sequences.sql` | Cria sequences |
| 3 | `03-seed-data.sql` | Insere dados fictícios |
| 4 | `04-views.sql` | Cria views didáticas |
| 5 | `05-indexes.sql` | Cria índices adicionais |
| 6 | `06-validation.sql` | Valida a instalação |

Os scripts são compatíveis com Oracle Live SQL.
