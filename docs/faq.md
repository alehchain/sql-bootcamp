# FAQ

## Preciso instalar o Oracle Database?

Não. Todos os exemplos essenciais podem ser executados no Oracle Live SQL.

## Preciso saber programação?

Não. O curso começa pelos conceitos fundamentais.

## Posso usar PostgreSQL, SQL Server ou MySQL?

Sim, mas alguns exemplos precisam de adaptação. Consulte `docs/compatibilidade-sgbds.md`.

## Onde estão as respostas?

Cada módulo possui um arquivo `solucoes.sql`. Tente resolver os exercícios antes de consultá-lo.

## Posso usar este conteúdo em aulas?

Sim, respeitando os termos da licença MIT e mantendo os créditos.

## Os dados representam pessoas ou empresas reais?

Não. Todo o conjunto de dados é fictício e voltado exclusivamente ao aprendizado.
