# Código de Conduta

Este projeto adota um ambiente respeitoso, inclusivo e colaborativo.

Não serão tolerados ataques pessoais, discriminação, assédio, divulgação de dados privados ou comportamento deliberadamente hostil.

Ao participar, seja claro, educado, paciente e construtivo. Problemas podem ser reportados por meio das ferramentas de moderação do GitHub.
