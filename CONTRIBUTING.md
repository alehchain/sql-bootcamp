# Como contribuir

Obrigado por considerar contribuir com o SQL Bootcamp.

## Fluxo recomendado

1. Crie uma issue ou comente em uma issue existente.
2. Faça um fork do repositório.
3. Crie uma branch descritiva: `docs/modulo-select`.
4. Faça alterações pequenas e focadas.
5. Valide os scripts no Oracle Live SQL.
6. Abra um Pull Request utilizando o template.

## Padrão dos módulos

Cada módulo deve conter:

- `README.md`
- `teoria.md`
- `exemplos.sql`
- `exercicios.md`
- `desafios.md`
- `solucoes.sql`
- `boas-praticas.md`
- `erros-comuns.md`

## Estilo SQL

- Utilize palavras-chave SQL em maiúsculas.
- Use aliases claros.
- Prefira uma coluna por linha em consultas extensas.
- Comente exemplos e soluções.
- Não utilize dados reais, sensíveis ou corporativos.
- Informe diferenças entre SGBDs quando relevantes.

## Commits

Exemplos:

- `docs: adiciona teoria do módulo SELECT`
- `feat: adiciona exercícios de window functions`
- `fix: corrige sintaxe Oracle no módulo MERGE`
